신규 소셜 회원 가입 진행

지금은 시작 플로우까지만 연결되어 있습니다. 이메일 인증은 테스트 가능하고, 최종 소셜 가입 완료 API는 다음 단계에서 붙일 예정입니다.




1. 이메일 인증코드 발송

2. 이메일 인증코드 검증


3. 닉네임 입력


4. 소셜 회원가입 완료

이 버튼은 registrationToken, email, nickname, 기본 약관 동의값을 묶어서 최종 가입 완료 API를 호출합니다.
